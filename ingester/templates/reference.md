## How to mark

This file uses the dossier shape exactly, so the scorer can compare it with a drafted dossier. Write one `## {{TID}}-Enn Title` section per episode with Span, Topic, Subject and Outcome. Under each, write one item block per claim, row or question you judge the transcript supports, with the grade you would expect and Verdict Accept. Mark claims the SMEs no longer perform as Status Retired, and claims they do but say they do not need as Status Current, not needed, so the scorer can count resurrections. Every citation is checked with `ingester/bin/check-citations`, so quotes are verbatim. Episodes with an outcome of Aside carry no items.
